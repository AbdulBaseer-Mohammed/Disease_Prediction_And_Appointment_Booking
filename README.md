Disease Prediction and Appointment Booking System

Project Overview

The Disease Prediction and Appointment Booking System is a web application developed using Python, Machine Learning, and Streamlit. It helps users identify possible diseases based on their symptoms and provides features to view doctor information and book appointments.

The main goal of this project is to make basic healthcare assistance more accessible through a simple and user-friendly application.

Features

- Disease Prediction: Predicts possible diseases based on selected symptoms using a Machine Learning model.
- Doctor Information: Displays doctor details and availability.
- Appointment Booking: Allows users to book doctor appointments.
- OTP Login: Includes an OTP-based login flow.
- Appointment History: Helps users view their appointment records.
- User-Friendly Interface: Provides a simple interface built with Streamlit.

How to Run the Project

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder

cd Disease_Prediction_And_Appointment_Booking

3. Install the required libraries

python -m pip install streamlit pandas numpy scikit-learn

Install any other dependencies required by the project.

4. Start the application

python -m streamlit run app.py

5. Open the application

Open the local URL shown in your terminal, usually "http://localhost:8501".
